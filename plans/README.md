# Plans

Shared planning directory for all AI assistants working on this project.

## How to use

- **One file per plan.** Name it descriptively: `phase-3-corpus-validation.md`,
  `fix-substring-alias-matching.md`, etc. — not numbered.
- **Use the template below** so any AI can parse the plan consistently.
- **Update status** as work progresses — don't leave stale plans lying around.
- **Archive completed plans** by moving them to `plans/done/` (create it if
  needed).

## Plan Template

```markdown
# [Plan Title]

**Status**: draft | agreed | in-progress | blocked | done
**Author**: [AI name or human]
**Created**: YYYY-MM-DD
**Last updated**: YYYY-MM-DD

## Goal

What we're trying to accomplish and why.

## Context

What you need to know to understand this plan. Link to relevant files,
WORKLOG.md entries, or HANDOFF.md decisions.

## Approach

Numbered steps. Be specific — file paths, function names, expected behavior.

1. ...
2. ...
3. ...

## Open Questions

Things that need a decision before or during implementation.

- [ ] ...

## Risks / Gotchas

What could go wrong or what to watch out for.

## Progress

Track what's done as work proceeds.

- [ ] Step 1
- [ ] Step 2
- [ ] Step 3
```
